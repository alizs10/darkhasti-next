# Auth Service Rewrite Plan

## Overview

Rewrite the entire authentication service: NextAuth config, axios instances, proxy (middleware), token refresh, and cleanup dead code. Goal: single source of truth for token refresh in the JWT callback, proper auth.js v5 patterns, clean code without debug logs.

## Architecture

**Token refresh happens in ONE place: the `jwt` callback in `auth.ts`.** Every other layer calls `auth()` / `getSession()` which triggers the JWT callback, which checks expiry and refreshes via `deduplicatedRefresh`. No manual JWT decode/encode anywhere.

```
proxy.ts → auth() → JWT callback → expired? → deduplicatedRefresh → new tokens → cookie updated
axios-server → auth() → JWT callback → attaches Bearer → 401? → auth() again → retry
axios-client → getSession() → /api/auth/session → JWT callback → attaches Bearer → 401? → retry
```
